# Worry Free Inc. Website

Production-ready Next.js App Router site for Worry Free Inc., a Troy, Michigan lawn care, landscaping, outdoor maintenance, and snow and ice control company.

## Stack

- Next.js 16 App Router
- TypeScript
- TailwindCSS 4
- shadcn/ui-style primitives
- Framer Motion
- lucide-react

## Commands

```bash
npm run dev
npm run lint
npm run build
```

## Routes

- `/`
- `/about`
- `/services`
- `/municipal-services`
- `/commercial-services`
- `/residential-services`
- `/seasonal-services`
- `/snow-ice-control`
- `/employment`
- `/contact`

The contact form validates locally and shows a success state. Connect an email, CRM, or server action provider before using it for live submissions.
